# Balcão PDV — atualizações

## Para baixar

| Programa | Versão | Baixar |
|---|---|---|
| **Balcão PDV** (caixa, estoque, notas) | 1.32.3 | [Balcao-PDV-Instalador-1.32.3.exe](https://github.com/kaizenknt/balcao-pdv/raw/main/instaladores/Balcao-PDV-Instalador-1.32.3.exe) |
| **Ficha de Pesagem** | 1.6.2 | [Ficha-de-Pesagem-Instalador-1.6.2.exe](https://github.com/kaizenknt/balcao-pdv/raw/main/instaladores/Ficha-de-Pesagem-Instalador-1.6.2.exe) |

Como instalar:
1. Clique no link e baixe o instalador.
2. Abra o arquivo baixado. Se o Windows mostrar um aviso azul, clique em **Mais informações → Executar assim mesmo**.
3. Pronto: o programa ganha atalho na área de trabalho e no menu Iniciar.

Não precisa de senha de administrador. Se o programa já estiver instalado, o instalador só atualiza e mantém todos os dados.
Depois de instalados, os dois programas se atualizam sozinhos: não é preciso baixar de novo a cada versão.

## O que fica aqui

Este repositório guarda só as **versões publicadas** do Balcão PDV e da Ficha de Pesagem.
Os programas instalados na loja procuram aqui as versões novas e se atualizam sozinhos.

Nenhum dado da loja (vendas, clientes, estoque) fica aqui.
